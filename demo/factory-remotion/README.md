# Feedback → Feature Factory (Remotion)

Motion-graphics demo — **not a website**. Built with `npx create-video@latest`.

## Run Remotion Studio

```bash
cd demo/factory-remotion
npm install
npm run dev
```

Opens Studio; play **FactoryPipeline** (1920×1080).

## Scenes

1. Title  
2. Scrape Google Reviews  
3. Sort / cluster agent  
4. List of PRs  
5. Designer / PM  
6. Engineer  
7. Code Reviewer / QA  
8. Human merge  
9. Production  

## Render

```bash
npx remotion render FactoryPipeline out/factory.mp4
```
